\# Evidence Documentation



This directory contains selected screenshots demonstrating the implementation, configuration, and validation of the Home SOC Lab.



The evidence is organised into categories to provide a clear overview of the lab infrastructure and its security monitoring capabilities.



\## Evidence Categories



| Directory | Description |

|---|---|

| `01-lab-architecture` | Network topology and virtual machine architecture |

| `02-wazuh-server` | Wazuh dashboard and server service status |

| `03-windows-endpoint` | Windows agent registration, Sysmon telemetry, and event collection configuration |

| `04-kali-endpoint` | Kali Linux agent registration and network configuration |

| `05-detection-and-alerts` | Custom detection rules and verified security alerts |



\## Screenshot Naming Convention



Screenshots use sequential numbering and descriptive filenames to make evidence easy to identify and reference.



\## Evidence Integrity and Privacy



\- Screenshots represent the actual lab environment and are captured from the relevant virtual machines or Wazuh dashboard.

\- Sensitive information, credentials, tokens, and private key material are excluded or redacted.

\- Screenshots are supporting evidence and should be interpreted alongside the corresponding configuration and technical documentation.

\- Detection-validation screenshots demonstrate controlled lab testing and should not be interpreted as evidence of a real-world security breach.
